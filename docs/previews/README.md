# Design previews

Browser mock-ups made before building a visual feature on the device. Open
them in a browser; they draw at the device's 480 × 222 pixels, shown at 2×.

| File | What |
|---|---|
| `splitflap.html` | Split-flap clock and its flip animation |
| `matrix.html` | Boot animation: new digital rain next to the classic one |
| `matrix_clock.html` | Matrix clock (time made of the rain's symbols) |
